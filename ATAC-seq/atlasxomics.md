# Spatial Epigenome Analysis Pipeline (DBiT-seq ATAC Analysis)

[![Documentation Status](https://readthedocs.org/projects/atlasxomics-atlasxpipeline-docs/badge/?version=latest)](https://atlasxomics-atlasxpipeline-docs.readthedocs-hosted.com/en/latest/SpatialEpigenome.html)

This repository provides a step-by-step downstream workflow for processing and visualizing **Spatial ATAC-seq** data generated by the **Deterministic Barcoding in Tissue (DBiT-seq)** protocol.

The analysis framework integrates **ArchR** for scalable single-cell ATAC processing (LSI dimension reduction, pseudo-bulk generation, peak calling, and chromVAR motif enrichment) with **Seurat** for spatially resolved visualization mapped back to tissue histology.

## Overview

Spatial ATAC-seq data produced via microfluidic barcoding (DBiT-seq) presents unique challenges due to high sparsity and grid-like spatial structures. 

This pipeline addresses these challenges by:
1. Managing large-scale genome accessibility matrices using ArchR’s HDF5-backed **ArrowFiles**.
2. Performing non-linear dimension reduction (**Iterative LSI**) on high-variable genomic tile bins (5 kb).
3. Aligning spot/tixel coordinates with histological images using Seurat's spatial object infrastructure.
4. Mapping transcription factor (TF) motif deviations across tissue sections using custom square-grid spot rendering.

## Input Data & Global Parameters
Required inputs:
1. fragments.tsv.gz: Aligned ATAC fragment file (e.g., generated via Chromap).
2. Spatial Folder: Directory containing image metadata, coordinate matrices (tissue_positions.csv), and low-resolution histology images from AtlasXBrowser.

Global Initialization
```
data_species  <- 'mm10'        # Reference genome ('mm10', 'hg38', etc.)
```
